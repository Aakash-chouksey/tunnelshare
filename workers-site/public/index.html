Agent era

Your agent needs a URL, not a laptop.

TunnelShare speaks machine first: upload returns JSON your agent can parse, the share payload is a link plus a 6-digit code, and every share dies on its own.

Structured output

Upload returns JSON with id, code, url. Agents parse it, verify bytes with curl, and report back.

Webhook-ready

Plain POST /api/upload and POST /api/download. No SDK, no auth dance, no open ports.

Ephemeral by design

1 / 24 / 72 h expiry, 1–100 download caps, 5-strike lockout. Interrupted transfers auto-resume.

Copy-paste agent prompt

Set up TunnelShare from scratch and prove it works.

1. Clone the repo and enter it:
   git clone https://github.com/Aakash-chouksey/tunnelshare
   cd tunnelshare
2. Install and run (Python 3.10+ required, cloudflared required for the tunnel step):
   ./setup.sh --run  (serves http://127.0.0.1:8080 — keep it running)
3. Verify with curl:
   - Upload: curl -s -F "file=@README.md" http://127.0.0.1:8080/api/upload
     (expect JSON with id, code, url)
   - Download: curl -s -X POST -H 'Content-Type: application/json'
     -d '{"id":"<id>","code":"<code>"}' http://127.0.0.1:8080/api/download -o /tmp/ts-verify
     and confirm the bytes match the uploaded file.
4. Open a public URL:
   cloudflared tunnel --url http://127.0.0.1:8080
5. Report back: local URL, public tunnel URL, and the upload-plus-download verification result.

Full checklist lives in AGENT_SETUP.md in the repo at github.com/Aakash-chouksey/tunnelshare.

Setup

Install, run, share

From clone to public link. Sample share below the steps is live in your browser only.

01

Install cloudflared

# macOS
brew install cloudflared

Linux / Windows: grab the binary from the Cloudflare docs.

02

Run your app

# one command — venv, deps, serve :8080
./setup.sh --run

Manual path: pip install -r requirements.txt && python app.py.

03

Open the tunnel

# HTTP/2 transport: QUIC stalls through VPNs
TUNNEL_TRANSPORT_PROTOCOL=http2 cloudflared tunnel --url http://127.0.0.1:8080

You get something like https://olive-dog-41.trycloudflare.com.

04

Share the link

# share payload: link + 6-digit code
https://olive-dog-41.trycloudflare.com/s/a1b2c3d4
code: 482910 (shown once)

Receiver enters the code to unlock the download. Interrupted transfers auto-resume.
